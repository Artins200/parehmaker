# parehmaker

PWA-приложение **«Джентльмен»** — система онлайн-записи в мужскую парикмахерскую
с кабинетами для клиентов, барберов и администратора.

- Исходники: [`barber-app/`](barber-app) — vanilla JS, без сборки и зависимостей
- Документация и доступы: [`barber-app/README.md`](barber-app/README.md)

## Быстрый старт

```bash
cd barber-app
python3 -m http.server 8080     # открыть http://localhost:8080
```

Приложение открывается на экране «Записаться» с уже добавленными демо-барберами.
Вход администратора: `ADMIN777` / `777`. Записаться можно и без регистрации — гостем.

## Что внутри

| Экран | Назначение |
|---|---|
| Салон | галерея, барберы с рейтингом, услуги и цены, контакты |
| Записаться | барбер → услуга → дата в календаре → время → подтверждение |
| Мои записи | активные, выполненные и отменённые визиты, повторная запись, оценка |
| Аккаунт | вход/регистрация, профиль, кабинет барбера, панель администратора |

PWA: `manifest.json` + Service Worker (`barber-v1`), установка на домашний экран,
работа офлайн, standalone-режим, тёмная и светлая темы, safe-area для iPhone.
