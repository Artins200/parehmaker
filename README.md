# parehmaker

PWA-приложение **«Джентльмен»** — система онлайн-записи в мужскую парикмахерскую
с кабинетами для клиентов, барберов и администратора.

- Исходники: [`barber-app/`](barber-app) — vanilla JS, без сборки и зависимостей
- Документация и доступы: [`barber-app/README.md`](barber-app/README.md)

## Быстрый старт

```bash
cd barber-app
python3 -m http.server 8080     # открыть http://localhost:8080
```

Приложение открывается на экране «Записаться» с уже добавленными демо-барберами.
Вход администратора: `ADMIN777` / `777`. Записаться можно и без регистрации — гостем.

## Что внутри

| Экран | Назначение |
|---|---|
| Салон | галерея, барберы с рейтингом, услуги и цены, контакты |
| Записаться | барбер → услуга → дата в календаре → время → подтверждение |
| Мои записи | активные, выполненные и отменённые визиты, повторная запись, оценка |
| Аккаунт | вход/регистрация, профиль, кабинет барбера, панель администратора |

PWA: `manifest.json` + Service Worker (`barber-v3`), установка на домашний экран,
работа офлайн (включая встроенные фотографии), standalone-режим, тёмная и светлая темы,
safe-area для iPhone. Кнопка установки — в шапке и в «Аккаунте»; для iPhone, Android
и встроенного просмотра есть отдельные инструкции.

**На телефоне открывайте сайт по HTTPS в Safari или Chrome.** По обычному HTTP-адресу
локальной сети (`http://192.168.…`) установка и Service Worker недоступны.
В предпросмотре сначала откройте приложение в отдельной вкладке, не внутри iframe.

## Публикация: где держать сайт

Чтобы приложение работало на телефоне, нужен **постоянный HTTPS-адрес**.
**Cloudflare Drop для этого не подходит**: это временный предпросмотр. Если за 60 минут
не нажать «Claim» и не войти в аккаунт Cloudflare, Cloudflare удаляет сайт вместе с его
временным аккаунтом ([документация](https://developers.cloudflare.com/workers/platform/claim-deployments/)).
Установленная на телефон иконка остаётся, а адреса, который она открывает, уже нет —
«Не удалось получить доступ к сайту». Повторная загрузка в Drop, как правило, создаёт
**новый адрес**, а у нового адреса свои данные (всё хранится в `localStorage` своего адреса)
и своя установка: для приложения, которое ставят на телефон, адрес должен быть стабильным.

| Вариант | Адрес | Как обновлять | Что нужно |
|---|---|---|---|
| **GitHub Pages** (рекомендуется, уже настроено) | `https://<логин>.github.io/parehmaker/` | автоматически после слияния в `main` | один раз включить Pages |
| **Cloudflare Pages**, загрузка перетаскиванием | `https://<проект>.pages.dev` | «Create a new deployment», адрес тот же | бесплатный аккаунт Cloudflare |
| Netlify, Vercel | `*.netlify.app`, `*.vercel.app` | перетаскиванием или из Git | бесплатный аккаунт |

**GitHub Pages** (workflow уже лежит в `.github/workflows/pages.yml`):

1. Репозиторий → **Settings → Pages → Build and deployment → Source: GitHub Actions**.
2. Слейте изменения в `main` (Pull request → Merge). Публикация запустится сама;
   если Pages включили позже слияния — **Actions → «Публикация на GitHub Pages» → Run workflow**.
3. Адрес появится в выполненной задаче и в Settings → Pages.

**Cloudflare Pages** (если хочется остаться в Cloudflare): панель → **Workers & Pages →
Create application → Get started → Drag and drop your files** → имя проекта → перетащите
папку `barber-app` (в ней должен лежать `index.html`) → Deploy
([инструкция](https://developers.cloudflare.com/pages/get-started/direct-upload/)).
Для обновления в том же проекте нажмите **Create a new deployment**.

После публикации на телефоне: откройте **новый** адрес в Chrome или Safari, дождитесь
надписи «Офлайн-режим готов» (вкладка «Аккаунт»), затем установите приложение.
Старую иконку с прежнего адреса удалите.

### Если пишет «Не удалось получить доступ к сайту»

1. Откройте адрес сайта в обычной вкладке браузера. Не открывается — сайт удалён или
   хостинг временный (Cloudflare Drop): опубликуйте заново по инструкции выше.
2. В браузере открывается, а из иконки нет — обновите сайт, удалите иконку и установите заново.
   Так бывало у копий до версии кэша `barber-v3` (см. ниже).
3. Не открывается только в мобильной сети или только у некоторых операторов — в России
   провайдеры с июня 2025 года ограничивают соединения с Cloudflare (страница загружается
   лишь частично), а в мае и июле 2026 были сбои с GitHub. Проверьте Wi-Fi и другого оператора.

> **Исправлено в `barber-v3`.** Cloudflare Workers и Pages отвечают на `/index.html` редиректом
> на `/`. Service Worker сохранял такой ответ, а браузер не принимает его на запуск приложения:
> оно не открывалось с домашнего экрана даже при работающем сайте. Теперь оболочка кэшируется
> «чистой» копией, `start_url` указывает на `./`, а уже установленные копии обновляются сами,
> как только на их адрес выложена новая версия.

## Проверки

Приложение по-прежнему работает без сборки и npm-зависимостей в браузере.
Для регрессионных тестов нужны Node.js 22+, Python 3 и Playwright:

```bash
npm ci
npx playwright install --with-deps chromium webkit
npm test
```

Отдельно: `npm run test:unit` или `npm run test:browser -- --project=android-chromium`.
Тесты проверяют мобильные фото, миграцию сохранённых данных, офлайн-запуск, установку
и работу в корне сайта, во вложенной папке и на хосте с редиректом `/index.html → /`
(как у Cloudflare Workers и Pages; тестовый сервер отдаёт его по адресу `/cloudflare/`).
