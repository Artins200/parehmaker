# Встроенные демо-фотографии

Фотографии хранятся рядом с приложением, а не загружаются с внешнего CDN.
JPEG оптимизированы для мобильных устройств (400×400 для аватаров, до 900×600
для галереи; все шесть файлов вместе — около 270 КБ). Service Worker кэширует
их при установке, включая ещё не открытые фотографии галереи.

Это демонстрационные стоковые фотографии, не фотографии настоящих сотрудников
или конкретного салона. Источники — Unsplash ([лицензия](https://unsplash.com/license)):
